## 📁 디렉토리 구성 안내

각 전략 폴더는 다음 두 가지 핵심 파일로 구성되어 있습니다:
1. **`GUIDE.md`**:
   - 전략의 철학(Philosophy)
   - 진입(Entry), 익절(Take Profit), 손절(Stop Loss)의 구체적 규칙
   - 실전 체크리스트 및 주의사항
2. **`strategy.ts`**:
   - 전략의 메타데이터와 파라미터 정의
   - 실시간 주가 입력 시 목표가/손절가/손익비를 계산하는 `evaluate()` 함수

---

## 💡 모의투자(Paper Trading)에 적용하는 방법
1. 웹 대시보드에서 **[모의 트레이딩]** 창을 엽니다.
2. 상단의 **전략 선택**에서 테스트해보고 싶은 기법(예: `Selah 탑다운` 또는 `20일선 눌림목`)을 선택합니다.
3. 해당 전략이 제시하는 **진입 타점, 목표가, 손절선, 손익비**를 확인한 후 가상 매수를 실행합니다.
4. 거래 일지에 어떤 전략으로 진입했는지 기록되며, 30일 후 나의 승률과 손익비를 검증합니다.
